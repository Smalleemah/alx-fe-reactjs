# React Query Demo

## Objective

This project demonstrates advanced data fetching and state management in React using React Query.

## Features

- Fetch data from JSONPlaceholder API
- Display posts using React Query
- Loading and error handling
- Data caching for improved performance
- Manual refetch functionality

## API Used

https://jsonplaceholder.typicode.com/posts

## Technologies

- React (Vite)
- React Query (@tanstack/react-query)
- JavaScript

## How It Works

- React Query fetches posts using the `useQuery` hook.
- Data is cached to reduce unnecessary API calls.
- A refetch button allows manual data updates.
- Loading and error states improve user experience.

## Installation

```bash
npm install
npm run dev
```
